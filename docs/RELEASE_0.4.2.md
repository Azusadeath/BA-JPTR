### 优化与修复

- 新增“迁移旧版修改”：游戏更新并确认新底稿后，可将旧版单条及批量修改迁移到当前版本，工具页也保留手动入口。原文、来源及修改关系能够核对的内容自动迁移；数量变化或存在冲突的内容逐组确认，无法核对的旧记录保留。迁移前自动备份修改记录，并支持撤销、重做。
- 修复查找结果加载第二页后，编辑文本、替换选中文本提示“位置已变化”的问题；连续加载多页后仍可正常编辑和保存。
- 查找关键词统一去掉首尾空白，避免多输入一个空格就找不到已有文本。首次搜索建立临时磁盘索引，后续分页和来源筛选复用索引，加载更多时只计算新增行的本次文本，减少大结果集的重复扫描和计算。
- 未连接游戏、底稿未就绪或任务进行中时，禁用加载更多及相关编辑入口；加载过程中双击已有行不再取消分页。选中后的操作工具栏移到表头上方，保留列名可见，选择变化时列表位置保持稳定。
- 工具页新增“打开备份位置”和“尝试重建”。底稿损坏时，只使用能与原记录核对、并通过完整校验的原始资源重建；确认后才执行，损坏底稿完整保留。无法找到可靠原文时明确提示，不把已替换的文本当作初始底稿。
- 修改记录读取失败时，主界面持续显示处理入口，可打开数据目录，或确认“归档并重置”损坏的那类记录；原文件完整保留，其他记录不受影响。设置读取失败时显示可关闭的明显警告。
- 修复来源表同步时规则和历史可能只保存一半的问题，增加成组保存、失败回滚和中断恢复。应用状态文件读取失败、损坏或格式异常时明确报错并保留文件，不再静默当作空状态。
- 文本导出改为整批准备、失败回滚，保留原有文件和无关内容；回滚受阻时明确标记导出未完成并保留恢复副本，再次向同一目录导出会先尝试恢复。失败写入会清理本次临时文件，以及未被游戏启用的新增资源副本。
- 错误提示按类型提供中文原因和操作建议，底层细节保留在日志；锁竞争与权限、路径错误分别处理。空表提示区分加载中、读取失败、任务进行中和正常空表，避免引导点击不可用的按钮。
- 校验 --data-dir 的目录层级，直接传入 .gui 或其中平铺的记录文件时明确提示正确位置，避免被误认为空数据目录。
- 移除内嵌中文字体，改用 Windows 系统的微软雅黑或黑体；精简未使用的直接依赖及相关许可材料，桌面程序体积明显减小。

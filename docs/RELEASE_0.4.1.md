### 优化与修复

- 修复后台内部异常后界面可能一直等待、无法继续操作的问题。现在会检测服务退出与连接中断，清除失效的等待和预览状态，并提供“重新连接”，从已保存记录恢复；原应用、恢复操作不会自动重试。
- 加载、来源核对、底稿初始化、导入导出等任务支持在准备阶段取消；最终提交仍保留写入保护，避免保存成功后误报取消。文本导出先写暂存目录，准备阶段取消不会覆盖已有导出文件。
- 游戏目录旁新增“保存”，手工输入或选择目录后确认保存才开始检查，输入停顿不再触发反复扫描；修改路径后显示等待提示，旧路径的检查结果不会覆盖当前状态。
- 工具页按“游戏与底稿 / 工作区 / 文件输出”分组。“检查底稿”放在“打开底稿位置”和“恢复初始底稿”之间，资源版本移入“底稿详情”；“跳过含日文假名的文本”移到工作区，勾选前后保持白底。
- 查找页增加初始空状态提示；选中结果后以白底悬浮工具条提供操作，表格不再下跳。状态栏随页面更新，切回替换页不再显示查找结果数字。
- “导出文本”移到工具页，改名为“导出底稿文本”，明确导出的内容。
- “运行详情”改名为“查看日志”，底部提供“复制全部 / 导出日志”，正文支持等宽显示和部分选择复制。警告标橙、错误标红，等级由后台明确传递；普通日志不加前缀，日志不加时间戳。
- 统一复选框、下拉框与按钮的尺寸、圆角和配色，保留原有细浮动滚动条；复选框尺寸单独设置，下拉箭头保持原尺寸。
- 改进本地维护：构建后保留当前、上一组及运行中的程序，清理旧构建；写入应用回执时清理确认失效的已恢复记录，保留已应用记录和离线磁盘记录。

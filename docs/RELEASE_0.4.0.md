### 优化与修复

- 精简单条修改窗口：集中展示修改前后文本，多条记录通过左侧列表切换，突出编辑与移除操作；移除重复详情、来源表显示和多余的关闭按钮。
- 移除查找及相关窗口中的记录/字段显示与复制定位入口，保留按文本和来源检索。
- 将游戏目录、底稿检查、词表导入导出、输出目录和恢复操作集中到“工具”页；未连接游戏或底稿需要处理时，主界面仍直接显示目录入口。
- 新增“关于 BA-JPTR”，可查看版本、构建信息、使用说明、项目仓库、开源许可及历史版本。
- “打开输出目录”始终可用，固定打开工具目录下的 output 文件夹，首次启动时自动创建。
- 修复检查底稿期间游戏目录短暂变为可编辑状态的问题；来源表就绪消息每次同步只显示一次。
- 移除重复的“已连接”标记，将运行消息统一放入底部状态栏；统一“正则模板”表述，精简替换页统计及恢复说明，将恢复按钮与底稿位置入口放在一起。
- 清理过时的发布审阅脚本，保留有效测试和必要验证流程。

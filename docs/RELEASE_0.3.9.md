### 优化与修复

- **来源范围**：词条仅作用于明确选中的来源表，移除“不限来源”。旧版来源留空的词条按同一游戏上次记录的来源表固定范围，迁移前保留旧词表副本；缺少可靠记录时提示手动选择，不自动扩大范围。
- **新增来源提醒**：游戏新增来源表后，提示哪些现有词条在新表中命中，并显示来源、命中段数与原文示例，可直接进入词条编辑。提醒遵循匹配方式和跳过假名选项，不自动勾选新表，未读提醒在重启后保留。
- **来源候选筛选**：添加或编辑词条后打开“选择来源表”，按当前原文字及包含、整段相同或正则方式提供命中的表；原文字为空时显示全部表，无命中时显示空列表。后台读取并缓存候选，取消后可重试，忽略过期响应；已有但被筛掉的勾选仍保留，不因查看候选而改动原范围。
- **来源选择精简**：选择操作统一为“全选 / 清空 / 反选”，仅作用于当前列表；移除“全部来源表…”菜单、“表详情”和手动添加表名，避免重复入口和无效范围。
- **预览滚动**：修复鼠标滚动预览表格时，下方文本对照区域跟着滚动的问题；表格和详情分别保留滚动状态。
- **窗口与按钮**：运行详情按日志内容收窄窗口，长日志换行显示，减少右侧空白；“词表”菜单按钮统一工具栏字体、背景和禁用样式。

### 已知限制

同一轮仍按“整段相同 → 包含文字 → 正则”的优先级处理原文，包含规则可能占用正则需要匹配的位置。零命中提示目前仅保留最先记录的原因，可能先显示范围外命中，而未显示所选范围内的重叠冲突。

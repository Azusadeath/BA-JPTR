### 优化与修复

- 移除“不限来源”功能。
- 游戏新增来源表后，提示哪些现有词条在新表中命中，并显示来源、命中段数与原文示例，可直接进入词条编辑。
- 添加或编辑词条后打开“选择来源表”，按当前原文字及包含、整段相同或正则方式提供命中的表；原文字为空时显示全部表，无命中时显示空列表。后台读取并缓存候选，取消后可重试，忽略过期响应；已有但被筛掉的勾选仍保留，不因查看候选而改动原范围。
- 选择操作统一为“全选 / 清空 / 反选”，仅作用于当前列表；移除“全部来源表…”菜单、“表详情”和手动添加表名，避免重复入口和无效范围。
- 修复鼠标滚动预览表格时，下方文本对照区域跟着滚动的问题；表格和详情分别保留滚动状态。
- 运行详情按日志内容收窄窗口，长日志换行显示，减少右侧空白；“词表”菜单按钮统一工具栏字体、背景和禁用样式。
- 修复在“查找”和“恢复”页切换时，“更改目录”“检查底稿”按钮偶尔闪灰的问题：同一游戏、同一底稿复用已完成的来源同步；换目录或更新底稿后重新核对，实际写入期间仍保留禁用保护。

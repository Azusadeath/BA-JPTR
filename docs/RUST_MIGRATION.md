# 纯 Rust 迁移

GUI、项目服务、命令行、启动器、正则和构建已移除 Python 依赖。0.3.0 使用统一的新数据格式，本机旧数据已完成一次性转换。
旧 Python 实现和测试移到项目外恢复存档，黄金数据保留于 Rust 测试；不再提供 C ABI 或兼容界面回退。

## 模块

| 模块 | 职责 |
| --- | --- |
| bajptr-core | 页加解密与认证、FlatBuffer、SQLite、规则与差异统计 |
| bajptr-project | 存储、修订与锁、底稿、模板、定点修改、验证发布、撤销与后台任务 |
| bajptr-desktop | eframe / egui 原生界面，直接通过 channel 调用项目服务 |
| bajptr-cli | 用户命令及诊断 JSON Lines 协议 |
| bajptr-launcher | 读取版本清单并启动原生 GUI |
| bajptr-brand | 统一生成窗口与 EXE 多尺寸图标，构建时嵌入资源 |

工作线程保留原 action / result 合约。请求 ID、接受与取消、过期快照回退，防止晚到结果改写新操作。
GUI 与 CLI 共享词表、资源定位、底稿和安装恢复规则。

## 数据与发布

修改文档分别加载和验证。内容 SHA-256 修订、跨进程锁与原子写入防止丢失和外部覆盖。
JSON 统一 format 2，定点修改使用具名对象，应用状态与模板指纹直接使用紧凑 JSON 摘要。
底稿按游戏、版本隔离；只读取新版底稿，不扫描历史 manifest，不提供旧记录恢复。
TSV 固定五列，旧参数与旧格式分支已移除。一次性转换工具完成本机转换后已移出项目，不进入发行包。
安装从底稿重建，定点修改必须匹配原文；事务暂存期间失败或正则超限禁止发布。
全部页认证、CRC、回读解密和 SQLite integrity_check 通过后，再核对资源身份、完整 catalog、词表与定点记录。
先发布资源，再原子切换 size / CRC。恢复不回滚 hash，不删除其他资源。
Windows 原子替换使用扩展长度路径，支持中文与深层目录。
成功暂存由同一 Rust 二进制的独立清理模式整理，需目录前缀、随机令牌与标记匹配；失败暂存保留。
文件默认移到 Windows 回收站；设置 BAJPTR_TRASH_DIR 时先尝试指定目录，失败时回退到回收站，不永久删除。

## 正则边界

使用 fancy-regex 的线性快速路径与有界回溯，支持反斜线分组替换语法。
使用旧组件的真实结果验证 Unicode、大小写、末尾换行、空匹配及相邻非空匹配。
回溯上限 100,000；迭代检查处理时间、限制输出长度。错误贯穿事务与项目服务，不能被吞成普通未命中后继续安装。
字符名形式 `\N{…}` 等未支持语法明确拒绝，没有 Python 回退；不是对所有 Python 正则方言的等价声明。

## 开发

使用 tools/build.ps1、tools/package.ps1 和 tools/smoke.ps1。
构建自动选择隔离或系统工具链，默认锁定依赖；按二进制摘要发布，再更新清单。
发行包只包含启动器、清单引用的程序与运行库、文档及示例，不包含个人数据和开发环境。

应用自有代码均为 Rust；SQLite 和 Windows 系统库等第三方底层组件包含 C / 系统实现。
项目工具链目录中存在第三方附带的 Python 调试与代码生成脚本，构建与运行本应用均不执行它们，发行包也不包含它们。

## 本轮验证（2026-11-07）

- 103 组原有内核黄金用例及额外正则对照。
- 模拟完整流程：重复重建、定点与选中批量修改、共享撤销、外部冲突、坏词表、晚到取消、过期预览、不完整底稿、损坏和缺失原资源的恢复。
- 便携包在只含 Windows 系统目录的 PATH 下完成查找、编辑、生成、模拟安装、导出、恢复。
- 实际窗口验证启动、查找、双击、多行编辑、保存、预览与未命中说明；保留当前字号与布局。
- 真实游戏只读对照：56 表、577,381 行、30 条定点修改、16,155 字段变化、0 解析失败。查找、预览、状态及全部最终文本 BLOB 与旧实现相同，游戏身份未改变。

本机同次测试：首次查找约 1.30 秒，首次预览约 1.89 秒，缓存预览约 0.044 秒；旧实现预览约 13.63 秒。
移出耗时清理后，生成及回读校验约 4.61 秒，约 5.09 秒返回。
模拟资源首轮 UI 调用约 0.110 秒，项目读取约 0.149 秒。未清空 Windows 文件缓存，不是严格冷启动或屏幕呈现时间。
完整游戏 schema 仍缺失；结构与认证检查不能替代完整格式定义。

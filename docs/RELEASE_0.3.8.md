### 优化与修复

- **预览与应用**：主入口统一为“预览并应用”。显示预览时后台准备补丁，核对后点击“应用到游戏”，无需重复重建和加密；关闭预览后，当前会话内可复用已准备的补丁，修改规则、记录或选项后自动失效。确认应用前仍会校验资源，预览和准备不会改动游戏。
- **查找操作**：修改搜索文字后立即清空旧结果与选择，避免操作过期文本；支持在搜索框按回车查找，并防止输入法组词或提交候选时误触发。
- **列表位置**：替换、查找和恢复页面分别保留滚动位置，修复切换页面后列表位置互相影响的问题。
- **界面空间**：已连接时压缩游戏目录区，宽窗口下查找文字与来源筛选同排，为结果表留出更多空间；稳定工具栏位置，词表导入、导出统一放入“词表”菜单。
- **界面精简**：查找页直接显示“导出文本”，移除只有一项的“更多”菜单，以及搜索框、来源筛选旁的重复标签和“切换即查”说明；结果未选择时收起操作栏，空表格保持全宽。同步清理来源选择、词条和模板窗口的重复操作指引，保留必要字段含义与风险说明。
- **单条修改**：新增文字、来源表和记录 / 字段筛选，支持精确定位及完整原文、修改结果对照；列表使用虚拟滚动，少量记录时窗口更紧凑。单条管理仍只显示单条记录。
- **批量范围**：稳定列表与详情分区，支持拖动分隔线；短文本前后同屏，长文本可独立滚动，底稿原文与批量前文字不同时同时显示三组内容。沿用双击批量条目后，在编辑窗口查看文本范围的入口。
- **来源选择**：明确区分“当前可见项”与“全部来源表”的选择操作，筛选时保留隐藏项的选择；手动表名收纳到高级选项，读取成功后可直接刷新。
- **提示说明**：取消表单后清理过期编辑、校验提示；补齐批量替换为空的删除含义，恢复页面与确认统一说明保留词表、单条及批量记录，并提醒先退出游戏。
- **按钮可读性**：修复蓝底按钮禁用后文字与图标难以辨认的问题；禁用态统一为浅灰蓝底、深灰文字，可用主按钮保持蓝底白字，禁用时仍不可点击。

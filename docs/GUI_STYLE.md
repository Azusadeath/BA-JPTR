# 原生 GUI 视觉规范

适用于 Rust 原生界面。涉及词条来源范围的交互，应与开发文档中的固定来源和新增表提醒行为一致。

- 默认内容尺寸为 1080 × 680，最小为 900 × 620；尺寸均为逻辑像素，不含系统标题栏。
- 中文采用 Microsoft YaHei UI，缺失时回退到黑体。正文 16，按钮 14.5，标题 20，辅助信息 12.5–13。
- 背景 `#F4F7FB`，正文 `#25364D`，辅助文字 `#606F84`，分隔线 `#E2E9F2`，主操作 `#1F69B5`，浅蓝选中背景 `#E9F3FE`。
- 导航使用“替换 / 查找 / 工具”，顶部只保留页面导航，不显示连接或应用状态徽标。应用状态与任务消息集中在底部状态栏，忙碌时优先展示任务进度。游戏目录与底稿检查放在工具页，未连接或底稿异常时直接在主界面显示目录区。检查期间保留原有连接状态，收到异常结果后再展示目录输入框。页签、工具栏、表格和底部操作明确分层。主界面“预览并应用”固定在替换页右下角，和预览内最终“应用到游戏”一样使用实色蓝按钮，编辑使用次级按钮；实际写入仍须在预览内确认。
- 常用图标直接绘制为统一线条，不依赖 Unicode 图标字体或额外图片加载。
- 共用按钮禁用时使用浅灰蓝底 `#E8EDF3`、深灰文字与图标 `#53647A`，避免父级禁用透明度重复淡化；仍保留原有禁用交互和可访问状态。可用主按钮保持蓝底白字。
- 表头与表格文字左对齐。长文本在单元格内省略，完整内容通过原有编辑窗口查看；整行支持选择与双击。
- 弹窗统一使用浅色标题、白色背景、圆角和轻阴影；长列表和长文本在各自区域内滚动，多行编辑区随窗口高度收缩。
- 文本编辑区用“未保存”标明草稿变化，“填回原文”只填入编辑框；底稿原文使用折叠区域。有批量替换时直接显示替换关系与实时结果，不用段落解释处理顺序。各编辑窗口不重复说明保存后再应用的流程。
- 预览准备中显示转圈与简短状态，就绪后直接启用“应用到游戏”，失败时显示原因和“重试”；不展示补丁复用等内部细节。关闭使用标题栏或 Esc，不提供重复的“取消”按钮，关闭预览不取消后台准备。
- 未命中词条直接显示原文、替换结果、来源表和原因，“定位词条”返回主表并选中、滚动到对应行；合并行按真实规则归属定位，不让用户按序号查找。
- 迁移核对中，“确认本组”为次级操作，“暂时跳过”保留待核对状态，最终“保存已确认”为唯一蓝色主操作；确认数量标明未保存，组数与文本段数注明单位。
- 错误窗口按底稿、记录等类别明确标题，恢复操作优先于“知道了”；记录使用“替换词表”“单条与批量修改”等名称，文件名和技术细节放在悬停信息及日志中。清空记录沿用独立确认，确认按钮用红色，原文件仍保留供恢复。
- 保存使用保存图标，确认使用勾选，填入与移出使用方向图标，应用到游戏使用提交图标；移出范围不使用删除内容的垃圾桶图标。图标与文字共同表达动作，不增加独立的图标入口。
- 查找页选中结果后，在表头区域悬浮白底、细边框、轻阴影的上下文工具条，不改变表格位置；单选和多选按原语义提供操作，打开弹窗时收起工具条。初始空状态显示“输入关键词查找游戏文本”，无匹配时显示“未找到匹配文本”。查看文本范围沿用批量编辑窗口内的入口，不占常驻工具栏位置，也不增加右键入口。
- 工具页分为“游戏与底稿 / 工作区 / 文件输出”，分组标题使用 17 号加粗蓝色，普通行标签使用辅助色，以独立内容块和间距区分。底稿按钮按“打开底稿位置 / 检查底稿 / 恢复初始底稿”排列，恢复保留独立确认；资源版本放在折叠的底稿详情中。进入工具页不自动发起检查。“导出备份 / 恢复备份”放在工作区，“导出底稿文本”放在文件输出区，查找页不再提供导出入口。
- 复选框、下拉框与按钮统一采用 36 高交互区、蓝灰配色和圆角；复选框局部使用 20 大小图标，其他控件图标仍为 14，避免放大下拉箭头。假名选项勾选前后保持同一白底，仅以勾选标记表示启用，不增加常驻蓝底或蓝框。滚动条保留原有的细浮动样式，平时细线显示，悬停时展开。
- 底部状态信息随页面恢复上下文；查找结果数字只在查找页显示，正在运行的任务仍优先显示进度。
- “查看日志”使用等宽字体、可选择文本和顶部留白，底部提供“复制全部 / 导出日志”，正文独立滚动并为操作栏保留空间；错误行使用红色，警告行使用橙色，并保留相应文本标记，普通信息不加前缀。等级从后台事件明确传递，未标注等级的信息按普通信息显示，不按文字关键词猜测。复制与导出使用相同内容，不加时间戳。
- “打开输出目录”放在工具页，默认可用，固定指向工具数据目录下的 output；启动时创建目录，点击时也确保目录存在，不随导出或应用结果改变。
- “关于 BA-JPTR”位于工具页底部，采用产品信息卡、快捷按钮、整行链接列表与默认折叠的构建运行信息；沿用蓝白样式，仅保留标题栏关闭入口。提供最新发布页、使用说明、仓库、历史版本与开源许可，不提供问题反馈。版本与许可读取 Cargo 元数据，构建时间、源码标识、目标与编译器由构建脚本写入；长内容在窗口内部滚动。
- 默认宽度下查找文字与来源筛选同排，窄窗口分排。回车只在关键词框聚焦、无输入法组词、非忙碌且关键词有效时执行原查找动作。
- 匹配方式下拉选项、选中值及主表统一使用“正则模板”；假名选项旁不重复展示词条与批量修改数量。
- 单条管理与批量范围共用文字筛选和全文展示能力，不强制共用分区。单条管理只有一条时直接显示前后全文，短文本紧凑呈现；多条时搜索与数量同排，左侧虚拟摘要列表与右侧全文对照可调比例。沿用主界面浅色背景、白色内容区及上方工具栏，编辑为蓝色主按钮，移除使用普通次级按钮；不显示来源表名称，列表仅展示原文摘要。仅保留右上角关闭入口，不设底部操作栏。批量范围、合并编辑和替换预览使用左侧虚拟摘要列表、右侧全文对照；左右分区可调宽度，列表与每段全文独立滚动。右侧在普通宽度下上下显示替换前后文字，足够宽时并排；有差异的底稿原文按需展开。
- 界面不展示记录/字段编号，不提供复制定位或编号筛选；搜索结果将空间留给文本和来源表。底层精确定位数据和写入校验保留。
- 多选来源列表只保留“全选 / 清空 / 反选”，作用于当前列表；不提供“不限来源”“全部来源表…”、逐行“表详情”或手动添加表名。筛选不丢失隐藏项选择；普通词条至少选择一张表，合并编辑可确认空来源范围。
- 新增来源命中采用按需提醒，列出词条、表名、段数和示例，可进入编辑后自行调整范围。不要为提醒新增常驻工具栏入口，不自动把新表加入词条。
- 绘制层回归测试覆盖 Ctrl 多选、Shift 连选与双击；关键写入操作没有全局回车快捷键。

颜色、字体和按钮图标统一维护在 `crates/bajptr-desktop/src/theme.rs`。保留原有异步加载、虚拟列表和共享只读数据。

- 初始底稿状态使用圆点：已验证为绿色，无已验证底稿为灰色，悬停显示状态文字。预览为 0 处变化时隐藏空表格和应用入口，保留结果说明、必要诊断和标题栏关闭入口；有变化时对照列使用“当前游戏文字 / 替换后的文字”。

- 零变化预览默认宽 420；编辑文本与普通批量替换默认宽 600，短文本仅预留两行，未预览时不创建空结果区。合并编辑默认宽 760，替换预览默认宽 780；合并编辑的设置区紧凑排列，来源表统一在“选择来源表”窗口维护，不在编辑器重复展示标签，剩余高度用于列表和全文。批量范围不再提供底部关闭按钮。

- 单条修改按空白、短文本、长文本和多条记录选择紧凑尺寸；筛选只剩一条时隐藏摘要列表，筛选无结果时收缩。批量文本范围默认宽 640（少量）或 760（多条），空结果收缩。迁移核对默认宽 640（单组）或 780（多组），单组直接展开内容，筛选无结果及核对完成后使用紧凑布局；来源选择、正则模板、关于默认宽分别为 480、560、520。
- 词条编辑、文本编辑、批量编辑、合并编辑、来源选择和正则模板不再重复提供“取消”按钮；标题栏 × 与 Esc 继续放弃当前草稿。恢复备份、底稿恢复和损坏记录重置等确认窗口保留取消分支。

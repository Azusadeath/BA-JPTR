# 原生 GUI 视觉规范

当前调整仅涉及 Rust 原生界面。词表、底稿、安装恢复及替换规则的处理逻辑保持原样。

- 默认内容尺寸为 1080 × 680，最小为 900 × 620；尺寸均为逻辑像素，不含系统标题栏。
- 中文采用 Microsoft YaHei UI，缺失时回退到黑体。正文 16，按钮 14.5，标题 20，辅助信息 12.5–13。
- 背景 `#F4F7FB`，正文 `#25364D`，辅助文字 `#647489`，分隔线 `#E2E9F2`，主操作 `#1F69B5`，浅蓝选中背景 `#E9F3FE`。
- 游戏目录保持单行；页签、工具栏、表格和底部操作明确分层。应用使用实色蓝按钮，预览与编辑使用次级按钮。
- 常用图标直接绘制为统一线条，不依赖 Unicode 图标字体或额外图片加载。
- 表头与表格文字左对齐。长文本在单元格内省略，完整内容通过原有编辑窗口查看；整行支持选择与双击。
- 弹窗统一使用浅色标题、白色背景、圆角和轻阴影；长列表和长文本在各自区域内滚动，多行编辑区随窗口高度收缩。
- 多选来源列表的“表详情”固定在右侧；筛选、全选、反选、清空和取消行为沿用现有逻辑。
- 新增的绘制层回归测试直接点击文字区域，覆盖 Ctrl 多选、Shift 连选与双击；没有添加应用命令快捷键。

颜色、字体和按钮图标统一维护在 `crates/bajptr-desktop/src/theme.rs`。保留原有异步加载、虚拟列表和共享只读数据。

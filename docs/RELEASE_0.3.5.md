### 优化与修复

- **搜索结果**：统计完整命中数量，每次加载 500 条，支持继续加载和按来源表筛选。
- **假名过滤**：查找遵循“跳过含日文假名的文本”选项；切换选项后清除旧结果，避免继续显示不符合条件的内容。
- **查找界面**：扩大结果表显示区域，理清查找、来源筛选与结果操作的层级；根据单选、多选显示对应操作，移除重复统计和状态列。
- **加载更多**：按钮固定为表格最后一行并水平居中，新结果追加到加载行之前，加载期间禁止重复触发。
- **文本显示**：搜索结果默认单行显示，换行折叠为空格；双击编辑时保留完整原始换行。
- **批量修改**：在“替换”主表中以一条“查找文字 → 替换文字”显示，来源表标注“批量修改”。同一游戏版本内，相同查找文字和替换文字的多次选择自动合并，只修改历次选中文本的并集，重复选择不会重复替换；支持编辑合并条目和整条移除。
- **单条修改**：入口只显示单项编辑记录；列表卡片铺满弹窗，编辑、移除按钮统一靠右，长文本自然换行，缩窄窗口与滚动到底均可正常查看。
- **应用与补丁**：移除“仅生成补丁”入口。补丁生成并校验通过后，若写入游戏失败，会自动保存完整补丁并提示失败原因、保存位置和本次尚未应用成功，排除占用或权限问题后可重试。

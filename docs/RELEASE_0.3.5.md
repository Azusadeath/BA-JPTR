### 优化与修复

- **搜索结果**：统计完整命中数量，每次加载 500 条，支持继续加载和按来源表筛选。
- **假名过滤**：查找遵循“跳过含日文假名的文本”选项；切换选项后清除旧结果，避免继续显示不符合条件的内容。
- **查找界面**：扩大结果表显示区域，理清查找、来源筛选与结果操作的层级；根据单选、多选显示对应操作，移除重复统计和状态列。
- **加载更多**：按钮固定为表格最后一行并水平居中，新结果追加到加载行之前，加载期间禁止重复触发。
- **文本显示**：搜索结果默认单行显示，换行折叠为空格；双击编辑时保留完整原始换行。
- **批量修改**：已保存的批量修改直接显示在“替换”主表，来源表列标注“批量修改”，可编辑或移除；“单条修改”入口恢复为只显示单条记录，编辑批量项后保留原有分类。
